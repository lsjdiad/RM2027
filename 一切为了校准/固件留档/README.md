# 固件留档（仓库外，防止被 esc-lab.sh 的"清孤儿固件"删掉）

`AM32-rm2027/firmware/*.bin` 是按**分支名**命名的，`esc-lab.sh` 在每次编译后会删掉
"分支已不存在"的 bin ⇒ 一旦某个分支被删，它的 bin 也会被清掉。
所以凡是**要长期保留**的固件，都在这里放一份，并记清"分支 + 提交 + 开关 + 哈希 + 重建命令"。

## 2026-10-14 那一对（补偿 ON / OFF，闭环额度都是 6000ms）

这一对的**唯一差别**是 `RM2027_STEP_GAINOFF` 一行（其余六个开关全同）⇒ 是干净的 A/B。

**永久 tag**：`留档/2026-10-14-补偿ON-闭环6s`、`留档/2026-10-14-基线OFF-闭环6s`
（tag 是永久 ref，不受分支删除/gc 影响 ⇒ 就算分支没了，代码也找得回来）

**重建命令**（任何时候都能从 tag 重新生成同一个 bin）：
```bash

sha256sum obj/AM32_RM2027_ESC_G071_2.21.bin         # 应等于上表哈希
```
