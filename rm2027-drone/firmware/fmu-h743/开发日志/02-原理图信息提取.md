## 三、⚠️ 曾经的错误结论（已推翻，保留作为教训）

> **2026-09-28 当天，本节原本写的是「引脚号无法从 PDF 提取，此路不通」—— 这个结论是错的。**
> 用户提醒「原理图本来就标注了」，改用**看图**后 30 分钟内拿到了完整引脚表。
> 保留这段是为了记住教训，不是为了留个错结论。

### 3.1 当时试了什么（失败的原因）

```text
用 pdftotext -bbox-layout 拿文字坐标 → 对每个网络名找欧氏距离最近的引脚名
25px 阈值：命中 0 个
70px 阈值：有命中但全是乱配（IIC11_SCL 与 IIC11_SDA 同时映射到 PB9）
```

### 3.2 为什么失败（三个真实原因）

```text
① 用「欧氏最近」而不是「同一根水平线」——网络名与引脚名相隔几十 pt，纯距离匹配必然乱
② 用「引脚名」当锚 —— 而图上引脚名是按「引脚号」排版、且名与号不总在同一行，
   符号里 VDD/VSS 这类没有 GPIO 名的引脚还会让名字列表整体错位
③ 从头到尾没看图 —— 明明 pdftoppm 渲染出来的图上字迹清清楚楚
```

### 3.3 ★ 正确的做法（可复现）

```bash
# 1) 渲染成图（矢量 PDF，任何 dpi 都清晰）
pdftoppm -r 300 -png FMU_飞控板_原理图_2026-09-24.pdf /tmp/fmu_img/fmu

# 2) 取带坐标的文字（只有坐标，不做匹配）
pdftotext -bbox-layout FMU_飞控板_原理图_2026-09-24.pdf /tmp/fmu_bbox.html

# 3) 关键：用「引脚号」当锚，按 y 坐标（同一根水平线）关联网络名
#    经验值：网络名中心 ≈ 引脚号中心（Δ≈0.7pt）；引脚名则偏 3.6~25pt，不可靠
#    引脚号的 x 列：H743 左列 ≈810、右列 ≈917（F103 左 ≈270、右 ≈384）

# 4) 引脚号 → 引脚名：查 STM32H743VI datasheet Table 9 (LQFP100)
#    本地就有：references/硬件手册/STM32H743VI_datasheet_extract.md
```

**两道交叉校验（必须做，否则不敢用）**：

```text
校验 A：看图。切条带渲染（300dpi 就够读），肉眼核对关键行
校验 B：把结果逐条对照 datasheet 的 Alternate function 表 ——
        合法复用功能应 100% 命中。本次 48 个信号引脚全部命中，故判定为「高置信」。
```

**产出**：`../引脚映射-H743.md`（按功能分组，board_config.h 可直接用）

### 3.4 顺带纠正的两处**

| 原以为 | 实际（看图确认） |
|---|---|
| PA7 → NRST7 | **PA7 = ✗ 未连接**（NRST7 是左侧复位电路的网络，位置靠近但无关） |
| PB1 → SW5 | **PB1 → TIM3_CH4**（SW5 是复位按钮的位号，不是网络名） |

> 这两处正是「纯坐标匹配」会踩的坑：**位号/分区标题混进了网络名候选集**。

## 三·旧 · ❌ 负结果：引脚号提取失败（**已被上面推翻**）

这是本次**第二个重要产出** —— 一个明确的「此路不通」。

### 3.1 试了什么

用 `-bbox-layout` 拿到全部 1342 个词的坐标，然后：

```text
候选引脚名 = 匹配 ^P[A-E]\d{1,2}$ 的词          → 找到 107 个（P A0..PE15）
候选网络名 = 匹配 SPI/IIC/UART/USART/CAN/GYRO/... → 找到 200 个
对每个网络名，找欧氏距离最近的引脚名
```

### 3.2 结果

```text
阈值 25px  → 命中 0 个
阈值 70px  → 有命中，但全是乱配，例如：
    IIC11_SCL  → PB9
    IIC11_SDA  → PB9      ← 同一引脚，不可能
    SPI12_MISO → PA8
    SPI12_MOSI → PA8      ← 同上
    SWDIO1     → PA13     ← SWDIO1 是 F103 的，PA13 是 H743 的
```

### 3.3 结论

> **PDF 文本对象的坐标与图形的引脚连线的几何邻接关系不对应。**
> 出版级 PDF 导出会打乱文本定位，此法**不可用**。

**据此决定（D-03）**：不再在 OCR 上花时间，
改为向硬件组索取**网表导出**或**引脚分配表**。

### 3.4 这个负结果的价值

```text
如果没记下来，下一个人（或三个月后的我）很可能再花两小时试一遍。
现在它躺在日志里，明确写着「此路不通」。
```
