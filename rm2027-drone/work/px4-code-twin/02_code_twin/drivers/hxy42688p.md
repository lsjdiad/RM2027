# `src/drivers/imu/hxy/hxy42688p/` —— 板载 1 kHz IMU（SPI1）

> **运行时一句话**：它是**唯一以 1 kHz 往 uORB 上发 `sensor_accel` / `sensor_gyro` 的发布者**，
> 跑在 **`wq:SPI1`**（本板优先级 **-2**，仅次于控制链的 0）上，**纯轮询、不用中断、不用 FIFO**。
> **⇒ 它是姿态控制环的"心跳源"。它停了，飞机就瞎了。**
> 行号基准 `源码根（见 `tools/source-root.conf`）` HEAD `3b5de24`。器件手册行号约定见 `work/PX4改造-索引与纪律.md` §2。

## 2. 每一拍干什么（`DataReadPublish`，[`HXY42688P.cpp:537`](hxy42688p.md#^src-src-drivers-imu-hxy-hxy42688p-HXY42688P-cpp-537)）

| 步 | 动作 | 说明 |
|---|---|---|
| 1 | 突发读 `0x0B~0x17`（13 字节） | 前提是 `COM_CFG.Addr_Auto = 1`（手册 §5.3）；驱动只读不改这个寄存器（设计取舍见 `work/PX4改造-索引与纪律.md` §3 第 2 条） |
| 2 | 取出 `DATA_STAT(0x0B)` 判两位 DRDY | `:548-553`；手册 §5.8 |

## 3. ★ 那个"线上没有 dummy 字节"的补丁（`transfer()`）

这是本驱动**唯一**改总线读写语义的地方（[`HXY42688P.cpp:803`](hxy42688p.md#^src-src-drivers-imu-hxy-hxy42688p-HXY42688P-cpp-803)）：

```c
int HXY42688P::transfer(uint8_t *send, uint8_t *recv, unsigned len)
{
    const bool is_read_transfer = (send && recv && len >= 2) && ((send[0] & DIR_READ) != 0);
    if (!is_read_transfer) { return SPI::transfer(send, recv, len); }

    const int ret = SPI::transfer(send, recv, len);      // 先按原生收

    for (int i = (int)len - 1; i >= 2; i--) { recv[i] = recv[i - 1]; }  // 整体右移一格
    recv[1] = 0;                                          // 空出来的第 1 字节置 0（dummy）
    return ret;
}
```

**为什么**：华轩阳这颗手册 §3.2.1 的读时序**没有 dummy 字节**，而 PX4 的 SPI 框架按"`[cmd][dummy][data…]`"布局解析
⇒ 在驱动侧把数据搬一格对齐，**不动框架、不动别的驱动**。

**⚠️ 两个副作用（读代码时要知道）**：
1. 它是 **in-place** 安全的（注释 `:801` 点明"必须在调基类之前读 `send[0]`"）。所以 `RegisterRead()` 用 `cmd[3]` 自收自发（`:825-830`）。
2. **所有读路径都多一次 memmove**。1 kHz 下这是每拍 13 字节的代价，可忽略；但**别在别的驱动里也这么做**。

## 4. 出错路径与可见性

| 现象 | 计数器 | 隔离方法 |
|---|---|---|
| 寄存器回读不符（配置被丢） | `_bad_register_perf` | `hxy42688p status` 会打印 `DATA_STAT` 与回读差异 |
| SPI 传输失败 | `_bad_transfer_perf` | |
| 数据与上一拍完全相同 | `_duplicate_sample_perf` | **持续增长 = 器件卡死**（不是"很安静"，见 `work/PX4改造-索引与纪律.md` §4 第 11 条） |
| DRDY 一直没置 | `_no_new_data_perf` | |
| 器件停转 | `_stale_sample_perf` | 触发 `Reset()`（[`HXY42688P.cpp:314`](hxy42688p.md#^src-src-drivers-imu-hxy-hxy42688p-HXY42688P-cpp-314)） |
| 温度读出无效 | `_invalid_temperature_perf` | |
| → 汇总上报 | `_px4_accel/_px4_gyro.set_error_count(...)` [`HXY42688P.cpp:309`](hxy42688p.md#^src-src-drivers-imu-hxy-hxy42688p-HXY42688P-cpp-309) | ★ **这个驱动会调 `set_error_count()`**（H104 不会），所以投票器能看到 `ERR CNT` |

**判据**：
```sh

listener sensor_gyro            # 频率应 ≈1000 Hz
listener sensor_accel
perf                           # 看 hxy42688p: duplicate sample / stale sample / bad transfer
```
