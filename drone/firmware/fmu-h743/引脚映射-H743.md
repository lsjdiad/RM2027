## 二、未连接 / 未使用（原理图上有 ✗ 标记或无网络）

```text
PE2 PE3 PE6  PC13 PC14(OSC32_IN) PC15(OSC32_OUT)
PA4 PA5 PA7  PB0  PB5  PB9  PB14 PB15  PD4 PD10 PD11
```

**特别注意**：图面批注「pa7 pA8 改成 timer1ch1 一对互补」**只落实了一半**：

```text
PA8 (67) = TIM1_CH1   ✅ 已接
PA7 (31) = ✗ 未连接   ❌ 没接（若要用 TIM1_CH1N，硬件需飞线）
```

> 这正是要找硬件组书面确认的点（`开发日志/04-待确认与风险.md` Q-01）。

## 三、⚠️ 没有找到电池电压采样

全图只有 4 路 **ESC 电流**采样（PC0/PC1/PC4/PC5），**没有 VBAT 分压到 ADC 的网络**。

```text
含义：飞控板自身可能不测总电压；电压可能由 ESC 板（G071）测后经 UART 上报，
      或需要飞线。
影响：PX4 的电池模块（CONFIG_DRIVERS_ADC_BOARD_ADC）启用时会找不到电压通道，
      首上电可能报电池告警 → 需确认后再决定是否启用。
    → 列入 04-待确认与风险.md
```

## 四、对 board 移植的直接结论

```text
✅ SPI1 = PB3(SCK)/PA6(MISO)/PD7(MOSI)    → 可在 nuttx-config 里配 SPI1
✅ I2C4 = PD12/PD13                        → 磁罗盘总线
✅ I2C2 = PB10/PB11                        → 气压计总线
✅ UART5 = PC12/PD2                        → DBUS 遥控（PX4 RC 输入）
✅ USART2 = PD5/PA3                        → 连 F103
✅ DShot = TIM1 CH1-CH4 (PA8/PE11/PE13/PE14)  → 直接支持，无需 DMA 冲突排查
✅ HSE = 25MHz                             → nuttx defconfig 关键值
```
