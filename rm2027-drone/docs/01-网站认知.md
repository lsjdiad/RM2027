### 1.2 站内检索路径

- 右上角搜索框可搜全站关键词。
- 无原生站内 API，net-read 的 site 过滤会被必应忽略；**可靠做法**：
  1. `net-read search '关键词' --engine baidu/sogou` 泛搜；
  2. 命中论坛文章链接后 `read --browser` 直读正文；
  3. 或直接在浏览器里逛专栏（wiki/4574 等）按时间/热度翻。

## 二、哔哩哔哩（bilibili.com）—— 教程、案例、炸机集锦

### 2.1 检索路径

- net-read 有 **B站原生 API 检索**：`net-read search '关键词' --engine bilibili`，直接返回视频 BV 号 + 标题，可进一步用 `api.bilibili.com/x/web-interface/view?bvid=...` 拿元数据（发布日期/时长/简介）。
- 拿 BV 号后：
  - 需要字幕 → 用 `bilibili-subtitle-downloader`/`fetcher` 技能（在 hana/elysia 侧有，共享侧可调用思路见 `memory/materials/bili-subtitles`，现有 21 个视频 ~1200 万字幕库存）；
  - 只看结构 → 直接看标题/简介 + 弹幕/评论。

## 四、检索纪律（防走偏）

1. **先看规则书**：空中机器人/蜂群具体机制以官方规则书为准（RM2027 约 9-12 月发布），社区传言只当线索不当结论。
2. **S/A/B 分级**：论坛开源正文、官方文档 = 高可信；B站标题党、短视频简介 = 低可信，只用来找线索，结论回原文核。
3. **低频检索**：百度/搜狗反爬严格，连续高频会被封 IP；命中即深读，不反复刷搜索。
