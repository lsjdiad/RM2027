
## 二、QGC 界面速查（5 个核心区）

| 区域 | 位置 | 干什么 |
|------|------|--------|
| 连接状态 | 左上角 | 飞机图标 + "Ready To Fly/Hold" + 电池——没图标=没连上 |
| **模式切换** | 顶部工具栏中间下拉 | **Hold/Position/Mission…** 起飞前先确认在 Position |
| **解锁滑条** | 左侧（需解锁时出现） | "Slide to arm"，从左滑到右 |
| **起飞/降落** | 顶部工具栏（Takeoff / Land / RTL 返航） | 点击后要滑确认条 |
| **虚拟摇杆** | 应用设置→General→Virtual Joystick | 没有遥控器时的手动飞行方式 |

### 常见坑（已踩过）
| 现象 | 原因 | 解法 |
|------|------|------|
| "Vehicle did not support the command" | 卡在 Hold 模式（SITL 无 RC 的自保） | 先切 Position 再起飞 |
| QGC 左上角无飞机 | SITL 没跑起来/被关了 | 检查 bat 窗口还在不在 |
| 看不到飞机画面 | 用了 headless bat | 用 start_sitl_headed.bat |
| Gazebo 窗口卡死 | 首次编译 shader 慢 | 等 1-2 分钟 |

### start_sitl_headed.bat 在干什么（逐行）
```bat
wsl.exe -d Ubuntu-24.04 -- bash -c "cd /home/drone/PX4-Autopilot && make px4_sitl gz_x500"
```
`make px4_sitl gz_x500` 一条命令 = ①增量编译检查 ②启动 Gazebo(3D世界) ③生成 x500 模型 ④启动 bin/px4 固件 ⑤gz_bridge 桥接(电机↔传感器) ⑥MAVLink UDP 14550 发心跳。
**bat 的意义**：wsl.exe 进程活着=VM 活着=SITL 活着；终端关掉 VM 8 秒闲置自杀，飞机跟着没了。
**headless 版**多了 `HEADLESS=1` 环境变量=不弹 3D 窗口。
