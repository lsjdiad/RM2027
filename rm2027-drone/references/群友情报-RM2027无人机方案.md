## 一、定位 / 感知方案
| 群友讨论 | 结论/方案 |
|---------|----------|
| 老师不让用动捕（觉得"作弊感"） | → 改做 **Swarm-LIO** 定位（无人机群 09-03） |
| 雷达锁定移动敌机 | 点云识别 vs 深度相机各有优劣；**远距离点云密度低易丢失**（无人机群 09-03 阿田） |
| Gazebo 定位特征 | 无纹理天花板/平地面 → **z 轴会飘**；解决：仿真里加带横梁天花板/大楼（无人机群 09-01） |
| Mid360 仿真 | GPU 加速；**WSL 不如双系统**（有性能开销）（无人机群 08-30） |
| 机载 IMU 用途 | 微空飞控 IMU 做惯性（外部定位短时兜底） |

## 二、飞控 / 控制方案
| 群友讨论 | 结论 |
|---------|------|
| PX4 断联解锁问题 | QGC 断联后遥控无法解锁 → 参数 **`COM_DL_LOSS_T`**（断联时间）/ **`NAV_DLL_ACT`**（关掉可不连QGC解锁，但失失控保护）（机场 09-02） |
| 自写 SO3 控制 | 有人写：Gazebo 仿真→实机；群友提醒"模型/密度要贴合实际"（无人机群 08-28） |
| 主流固件 | 群友仍 **PX4 / APM**（招聘 JD 也要求 PX4/APM）（无人机群） |
| PX4 二次开发 | 有人问（机场 09-03 末） |
| 遥控器 | 翼飞 c8 遥控器 350 出（机场 09-03） |

## 四、构型方案（RM27 249g）
| 构型 | 群友观点 |
|------|---------|
| **四旋翼** | 主流稳妥 |
| 固定翼/微固 | ★"别碰微固"——有人试过固定翼飞镖：机动/稳定/升力全不足、顶失速很赤石（机场 09-03 老登） |
| 垂起/尾座垂起 | 有人提"可能成方向"，但没实测 |
| 转机身代替云台 | ★"相机固定死=四旋翼飞镖"→ 转机身/单目旋转/双鱼眼，"宁死不用云台"（机场 08-31） |
| DJI Neo 参考 | ★"按 Neo 搓大概率没问题"；Neo1 pdd 579；想要 Neo edu/Neo2（机场 09-03） |

## 九、可借鉴结论（对我们）
1. **构型**：四旋翼 + 转机身（省云台重量）是最务实方向
2. **飞控**：PX4 主流，注意 `COM_DL_LOSS_T`/`NAV_DLL_ACT` 排障
3. **机载算力**：若走机载视觉 = RV1103 级（低成本）；我们 249g 走地面定位则不必带
4. **机库**：导向槽定位 + 捅触点充电，与我们方案一致
5. **心态**：现在预研练手（仿真/SITL + 硬件方案已定），别等规则背刺
