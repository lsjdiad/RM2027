## 一、课程是什么

- **性质**：浙江大学 FAST-Lab 官方免费开源课程（B站 + 深蓝学院同步），配套 GitHub `ZJU-FAST-Lab/Fast-Drone-250`（2494 star / 411 fork）。
- **内容**：从硬件组装 → 动力套焊接 → 飞控安装/接线 → 飞控设置与试飞 → 机载电脑(NUC) → Ubuntu/ROS 环境 → Ego-Planner 代码部署 → VINS 标定 → 实机实验，全套开源。
- **理论基础**（动力学/路径搜索/轨迹规划/建图）不在这门课里，需另学高飞老师在深蓝学院的课。

## 二、成本（采购清单实测，2022-2024 淘宝价）

| 类目 | 型号 | 价格 |
|------|------|------|

> 最大头：**机载电脑(NUC~3k) + 双目相机(D435~2.2k) + 飞控(1.1-2k)**。这三样≈7k，占了 3/4。

### 版本 B：上课低配版（省钱，仅入门验证）≈ **3500-4000 元**
- 机架48 + 电调35A 445 + 电机2306 345 + **pixhawk4 mini 1269** + **树莓派4B 600** + 遥控T8FB 269 + 3D打印100 + 电池250 + 杂项
- ⚠️ 树莓派跑不动 Ego-Planner，只能做基础验证，**不能完整复刻课程**。

### 版本 C：练手前置（强烈建议先买，成本几百）
- README 明确：**没有自稳飞行经验必须先练手**，推荐带保护圈的耐摔穿越机：mobula6 / 吉朗小金鱼85x / 化骨龙 racewhoop30（几百元）；或遥控器加密狗 + 模拟器（Steam Liftoff / 免费 FreeRider）。

> 💡 **对 RM2027 的适配提醒**：Fast-Drone-250 是 1.1-1.2kg 的大机（2306电机+4S+5寸桨）。RM2027 新规是 150-249g 微小型——**动力/机架/相机要大幅减重**，但 PX4/ROS/VINS/UWB/自主飞行的软件栈完全通用。学它的"方法与代码"，别照抄它的"硬件清单"。

## 三、学习周期（估算）

> 基于：课程 12 集视频（总长 ~90 分钟，纯看很快；动手才是大头）+ README 流程 + 你（电控出身）的水平。

### 有嵌入式/电控基础的人（你）：
| 阶段 | 内容 | 估算 |
|------|------|------|
| 0 | 装 PX4 SITL 仿真（L00） | 1-2 天 |
| 1 | 练手：模拟器 or 耐摔穿越机练自稳 | 建议并行 1-2 周 |
| 2 | 组装：动力套焊接 + 飞控接线 | 3-7 天（含等快递） |
| 3 | 环境：Ubuntu + ROS + NUC + Realsense | 1-3 天 |
| 4 | 代码：Ego-Planner + VINS 标定 | 1-2 周 |
| 5 | 试飞 + 调参（悬停/轨迹/安全） | 1-2 周 |
| **合计** | 从零到"能自主飞" | **4-8 周（一个月到两个月）** |

- 全职投入可压到 3-4 周；边上课边做，2 个月左右合理。
- **电控出身的你**可以跳过"学嵌入式"整块，重心直接放在：飞行操作、PX4 参数、ROS、VINS 标定、Ego-Planner——这块是全新的，也是最花时间的。
- RM2027 的额外增量（UWB 定位替代 GPS/VINS、249g 减重、机库充电）在课程之上再加，约 +2-4 周（主要是 UWB 接入 + 机库工程）。

## 四、学习路径建议（结合复刻目标）

1. **先看课程**：B站 BV1WZ4y167me（12 集）+ README 通读（已入库）。
2. **环境先行**：L00 装 PX4 SITL，先用仿真验证"能飞"（免费）。
3. **练手并行**：模拟器/耐摔穿越机练自稳（别跳过，README 血泪警告）。
4. **再上真机**：按采购清单攒一台（先按课程配置，成功后再为 RM2027 减重改造）。
5. **改造**：UWB 定位 → 机库 → 249g 减重 → 撞击/拦截任务。
