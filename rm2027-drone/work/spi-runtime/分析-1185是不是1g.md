# 分析：那 1185 counts 到底是不是 1g？（用已有数据能推出什么）

> 数据来源：`datadump.log`（2026-09-30，CPU halted，ST-Link 手工驱动 SPI1，静止 64 个样本）
> 配置：`ACC_RANGE=0x03`(±16g) · `ACC_CONF=0xAC` · `GYR_CONF=0xEC` · `PWR_CTRL=0x0E`
> 解析：`0x0C~0x17` **高字节在前**（手册 §4.1：`ACC_XH@0x0C`）

---

## 0. 先确认前提：板子当时是不是平的

```
加速度均值  X =  -50.3 counts   sd =  9.9
           Y =  +34.2 counts   sd = 29.7
           Z = +1183.0 counts  sd =  8.1
|a| 合矢量 = 1185.0 counts      sd =  8.0   (min 1164 / max 1205)
```

重力轴相对 +Z 的倾角 = `acos(1183/1185)` = **3.6°**

**⇒ 当时板子基本水平（3.6° 倾斜）。"Z 轴上那个大矢量就是重力"这个前提站得住。**

陀螺（静止）：

```
零偏 X = -3.2  Y = +17.2  Z = -7.9 counts  =  -0.20 / +1.05 / -0.48 dps
模长 1.17 dps   ← MEMS 陀螺正常量级（几 dps 以内）
```

⇒ **不像是坏器件；零偏和噪声都在正常范围。**

---

## 1. 一个反常现象

**Y 轴的噪声 sd=29.7 是 X(9.9)/Z(8.1) 的 3 倍。** 静止时三轴噪声应该差不多。
（没有结论，先记下来 —— 可能是某次真实的微小振动，也可能是这颗器件的怪癖。）

---

## 2. ★ 增益假说 vs 零偏假说：我能给出的旁证

两个假说在**单点静止**下**数学完全等价**，都预测"静止报 1185"：

| 假说 | 真实灵敏度 | 需要多大的零偏 |
|---|---|---|
| **A 增益误差** | 1185 counts/g（手册是 2048） | X/Y/Z 零偏都很小 |
| **B 零偏误差** | 2048 counts/g（符合手册） | **Z 轴要有 −865 counts（−0.42 g）的零偏** |

**按假说 B 算出来的三轴零偏：**

```
X: -50.3 counts = -0.0246 g
Y: +34.2 counts = +0.0167 g
Z: "缺" -865 counts = -0.422 g     ← 比 X/Y 大 17 倍
```

**⇒ MEMS 加速度计的零偏通常是几 mg 量级。单轴出现 0.42 g 的零偏极其反常。**
**而"整轴增益同比例偏 0.58x"会让三个轴一起偏小 —— 与 X/Y 零偏很小这个观测更自洽。**

**⇒ 旁证偏向【假说 A：增益误差】。但这只是旁证，不是证据。**

⚠️ 反方向的一条：子代理提到不同轮次之间 |a| 从 1185 变到 1231（+3.9%，约 5.7σ，不是噪声）。
**纯增益误差下 |a| 不随姿态变** —— 若那次确实是同一配置下转动板子测的，就说明存在零偏分量。
（存疑点：不同轮次的 `ACC_RANGE` 可能不同，需要原始数据才能确认。）

---

## 3. 结论与下一步

- ✅ **数据身份**：`0x0C~0x11` 是加速度计、`0x12~0x17` 是陀螺仪 —— 已由"四量程各自 8:4:2:1 缩放"
  这个功能实验证明（只有加速度计会随 `ACC_RANGE` 缩放），不是靠手册猜的。
- ✅ **静止时确实是 1g 量级**（板子水平，倾角 3.6°）。
- ❌ **但"1185 counts 是不是就等于 1g"（即标定系数对不对）仍未定论** —— 单点无法区分 A/B。

### 定论实验：**不要只翻一次，要转到 3 个正交姿态**

| 姿态 | 假说 A（纯增益） | 假说 B（有零偏） |
|---|---|---|
| 平放（Z 朝上） | \|a\| = 1185 | \|a\| = 1185 |
| 翻过来（Z 朝下） | \|a\| = **1185** | \|a\| = **1231~1283** |
| 侧立（X 或 Y 朝上） | \|a\| = **1185** | \|a\| = **≈572 或 ≈837** |

**判据：三个姿态的 |a| 是否一致。**
一致 ⇒ 纯增益误差（当前 1.7283 系数方向正确）；不一致 ⇒ 有零偏（当前系数偏大，必须撤）。

> 更严谨的等价实验：`ACC_SELF_TEST(0x6D)` —— 手册给了 `A_FS=3` 时 Z 轴 ±8g 的差分规格，
> **差分测量天然免疫零偏**：增益假说得 ≈9480 counts 差，零偏假说得 ≈16384 counts 差，差 73%，一次定论。

### 无论 A 还是 B，正规修法都是同一条

**跑一遍 PX4 的六面加速度计标定**（`CAL_ACC*`，QGC 里有向导）。
它同时估计 **3 个零偏 + 3 个刻度**，两种误差都能修 ——
所以那个手写的 `ACCEL_COMPAT_GAIN_CORRECTION{2048/1185}` 只是**临时拐杖**，
标定做完就应该撤掉（设成 `1.0`）。

> 前提：标定结果要能存住 —— 这个已经修好了（PX4 `be9f428`，片内 flash 参数存储）。

我曾说「板子基本是平的 ⇒ 结案是增益误差、不是零偏」。**这是错的，两条独立错误：**

1. **单点静止数学上不可能区分 A/B。** `raw = S·(1g + off)`，两个未知数一个可观测量。

2. **「板子平放」排除不了零偏。** 若零偏恰好落在**竖直轴**上，板子平放同样报 0.57g。
   我脑子里默认零偏在水平轴，才推出「零偏 ⇒ 板子该歪 24.5°」——这个前提没写出来、也没验证。
3. 本文档上半部分**早就写明** A/B 等价、未定论。我上一轮的下结论与自己的文档矛盾。

**反向旁证本来是偏向 B 的**：|a| 曾从 1185 → 1231（+3.9%）。纯增益下 |a| 与姿态**无关**。

## 3. ★ 陀螺刻度：这条「放飞红线」可以降级了

驱动常量 `BMI270::SetGyroScale()` = `radians(2000)/32767` ⇒ **16.3835 LSB/dps**
手册该档 = `1/0.061` ⇒ **16.3934 LSB/dps**

**⇒ 偏差 0.06 %，远在 ±1.5 % 规格内。陀螺刻度常量与手册一致。**

**结论：陀螺刻度不再是"来源不明的未知数"**，只剩「物理上是否真的准」这一项，需要一次转动/已知角速度复核。
（静止只能测零偏，测不了刻度。）

## 4. ⛔ 更正：上一轮我讲的 `0x70~0x7F` 寄存器**整段作废**

上一轮我照 **BMI270 官方寄存器图**讲了 `0x70 NV_CONF / 0x71~0x73 ACC_OFF_COMP / 0x78 GYR_USR_GAIN …`。
**我们这颗片子没有这些寄存器。** 手册 §4.1 通用寄存器表实证：

```
01 WHO_AM_I (0x6A)   02-03 Reserved    04 OIS_CONF    05 COM_CFG (0x50)
06 INT_CFG1  07 INT_CFG2  08 HPF&LPF_CFG (0x80)  0B DATA_STAT
0C~11 ACC_XH/XL/YH/YL/ZH/ZL      12~17 GYR_XH/XL/YH/YL/ZH/ZL
18~1A TIME_H/M/L    1C FIFO_CFG0   1D FIFO_CFG1(0x07)  1E FIFO_CFG2(0xFF)
1F FIFO_STAT0(0x40)  20 FIFO_STAT1  21 FIFO_DATA  22-23 TEMP_H/L
...
6D ACC_SELF_TEST   6F GRY_SELF_TEST   →→→  7D PWR_CTRL   7F SEG_SEL
```

- **`0x70`~`0x7C` 整段不存在**（0x6F 之后直接跳到 0x7D）。实测 `7C=03` 是读了一个不存在的地址。
- **`0x00` 也不是寄存器**（表从 `0x01` 开始）⇒ 我们 probe 里的「`CHIP_ID(0x00)==0x00` 兜底」是读空地址。
  真正的身份只有 **`WHO_AM_I(0x01) = 0x6A`**，手册缺省值明写 `0x6A`。
- 通用寄存器之外还有 **`SEG_SEL(0x7F)`** 分段：`0x83`→I2C_UN，`0x8C`→DIG_CTRL，`0x90`→点击/计步系数。
  配完必须写回 `0x7F = 0x00`。

**教训：不要拿 BMI270 的寄存器图当这颗片子的基准。** 两家有两处**看起来一样、地址一样**的寄存器
（`0x40/0x41/0x42/0x43` 名字和位定义都对得上），所以混用不会立刻报错，但会一错到底。

## 5. ★ 手册新线索（下一步上板实验）

**手册 §5.3 `COM_CFG(05h)`** —— 缺省 `0x50`

| 位 | 名 | 含义 |
|---|---|---|
| B7 | **BOOT** | **重载修调值**（0：正常模式；**1：重载修调值，置"1"后会自动复位为"0"**）|
| B6 | BDU | 块数据更新（缺省 **1**：输出寄存器在 MSB/LSB 被读走前不更新）|
| B4 | Addr_Auto | 地址自增，缺省 **1** |
| B1/B0 | OSIM/SIM | OIS/SPI 3 线 4 线 |

- 手册描述里明写「芯片内置高精度校准模块……对传感器的**失调误差和增益误差**进行精确补偿」，
  **补偿值就是"修调值"，而 `BOOT=1` 就是手册给出的「重新载入」手段。**
- **PX4 的 BMI270 驱动从来没有写过 0x05**（BMI270 没这个寄存器），我们也没有。
- **⇒ 上板实验（30 秒，可逆）：** CPU halted，读一次 `0x0C~0x11` 与 `0x05`；
  写 `0x05 = 0x50 | 0x80`（保留 BDU/Addr_Auto，只置 BOOT），等 1 ms，回读 `0x05`
  （应自动复位 B8→0），再读 `0x0C~0x11` 对比。
  若 |a| 明显变化 ⇒ 之前是「修调值没载入」，**那是我们自己的方法缺失，不是器件不符规**。
- ⚠️ 写 `0x05` 只动 1 位、手册明示自清零，**不是**上传微码那种危险操作。但仍按纪律：先记录范围、单成员独占 ST-Link。
