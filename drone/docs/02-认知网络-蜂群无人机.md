## 一、官方新规（RM2027 空中机器人）—— 第一手摘要

> 来源：官方 PPT 第 27-29 页 + 28 页。PPT 明确"后续可能微调/保留调整空间"，正式规则书发布后回填，但**方向已锁定**。

### 1.1 定位与形态
- **定位转型**："大尺寸空中火力平台" → "**小型空间智能机器人**"。
- **每局最多 4 架**，战队自制"**机库**"部署（机库最大收纳尺寸 **300×300×200mm**）。

### 1.2 使用方式
1. 局内**自动起飞**，执行任务后可落回场内，也可**飞回机库充电**。
2. **单次起飞续航至多 30s**（通过规范限制单机最高储能），可反复降落充电再起飞。
3. **原安全绳取消**，可在场内任意飞行。

### 1.3 典型任务（"空间智能"）
1. **直接撞击**对方前哨站/基地装甲 → 造成 **42mm 弹丸级别伤害**。
2. **主动迎击**改变对方飞镖和 42mm 弹丸弹道 → **拦截**。
3. **悬停获取信息**，有线或近场无线传回机库 → 供雷达等系统。

### 1.4 制作规范关键参数（第 29 页）
| 参数 | 数值 |
|------|------|
| 重量 | **基准值上限 249g，下限 150g** |
| 尺寸 | 基准值下限**直径 60mm**，上限 **140mm** |
| 尺寸-重量关系 | **线性**：如 200g → 不可超出 100×100×100mm 正方体 |
| 安全 | 机体外沿需**全包围桨保** |

> ⚠️ 官方原话："有人想做电磁发射吗？" 是给重装机器人(42mm发射模块 6kg/140V DC)的调侃——**无人机不含弹丸发射**，任务靠撞击/拦截/侦察。

## 四、技术判断（先记，细节在 03 实现路径）

1. **头号难题 = 场内无 GPS 的定位** → UWB 基站方案（ZJU 高飞已验证）+ 机载 IMU 融合，是当前最现实路线。
2. **续航 30s + 反复充电** → 挑战不是长续航，而是**能量管理 + 快速降落回库 + 充电效率 + 循环调度**。
3. **撞击/拦截是物理难题**：249g 全包围桨保下的撞击力、机动响应速度，需专门的动力学设计（这是新玩法，没现成开源）。
4. **重量预算严苛**：桨保、UWB 标签、传感器、电池、机架每克都要算，优先 150-200g 余量。
5. **4 架集群是"量变"**：单机先稳，集群协同（相对定位/任务调度）放后。
