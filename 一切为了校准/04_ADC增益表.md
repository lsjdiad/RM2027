# ADC 通道增益表（初步校准用）

> ★ **口径：用过零点位置反解，不是用幅值。**
> 理由：本数据里"悬空读数幅值"不是良定义的量——极差 / 分位数 / 拟合正弦幅值
> 三种口径给出的**大小顺序互相矛盾**；按它校正会把六步散差从 11.0°E 改坏到 51.7°E（实测）。
> 而零点位置对通道增益**极敏感**：d = g_P·v_P − g_0·V0，过零条件 v_P = V0·g_0/g_P，
> 而 v_n ≈ 母线中点（约 600 码）≫ 弧幅（150~350 码）⇒ 增益误差等效成 e_P 上一个
> 常数偏置 v_n(1 − g_0/g_P)，它**在同一个相的两个步里符号相反**（两步斜率反号）。
> 所以逐相搜索一个常量偏置，使该相两步的偏差对消即可（偏置码 ↔ 等效增益 g_P = 1/(1 − o_P/v_n)）。
>
> ## ★ V0 要不要一起校？——**不要，也不能单独校**
> `d = 悬空相 − V0`，四个通道（A/B/C/V0）**同时乘一个常数会整个约掉**。
> 有意义的只有三个比值 A/V0、B/V0、C/V0，扣掉一个整体尺度 ⇒ **自由参数只有 2 个**。
> 本表给的三相系数（已归一化到均值=1）正好把它们编码完 ⇒ **增益这一层是完备的**，
> V0 通道不需要、也拿不到一个额外的"增益校准系数"。
> （唯一会受影响的是固件里那个**绝对码值**的滞回阈值 16 码：四个通道同乘 k 会让
>   等效滞回变成 16/k，但相对 400 码级的弧幅是二阶小量。）
>

## 怎么用在固件里

在 ADC 采样完成、算出 `va/vb/vc` 之后、**减 V0 之前**，把每个通道乘以它自己的
**校正系数**（= 1/增益）：

```c
/* 通道级增益校正：占总预算为零（一次乘加）*/
va = (uint16_t)((uint32_t)va * GAIN_A_NUM / GAIN_A_DEN);
vb = (uint16_t)((uint32_t)vb * GAIN_B_NUM / GAIN_B_DEN);
vc = (uint16_t)((uint32_t)vc * GAIN_C_NUM / GAIN_C_DEN);
/* 之后照旧：悬空相 − V0 */
```

⚠ 三点注意：
1. **增益随采样点（CCR4）变**（交接 §3.3：A/C 比 0.47@130 → 0.89@260）
   ⇒ 这张表只对**产生它的那个 CCR4** 有效，换 CCR4 必须重测。
2. 归一化是任意的（三相同时乘一个常数不影响 d 的零点）⇒ 直接用上面的系数即可。
3. 校准只治【相内反对称】那一项；**剩下的【相间差】和它治不了的残余，才是下一步
   "消除六步不对称"要对付的东西** —— 见《一切为了校准/03_本轮结论.md》§新的下一步。
