## 四、由资源表得出的 5 条关键结论

### 1. 板子**没有 USB**
按网络名全表检索，**没有任何 USB 网络**（无 USB_DP/DM/VBUS）。
→ 所以「USB 直连飞控」这条路**在硬件上不存在**，必须走串口。

### 2. 但 UART 非常富裕
可用：`UART4 / UART5 / UART6 / UART7 / UART8 / USART3`
→ 拿任意一路当 **TELEM（MAVLink）口**即可，硬件上完全够。

### 3. 遥控器输入已经有了：`UART5 for DBUS`
图上明确标注。DBUS = 大疆遥控器协议，**PX4 原生支持**。
→ 遥控器直接飞 / 拨开关跑 mission，**不需要写任何代码**。

### 4. ★ F103 是「伴生 MCU」，不是 PX4IO
证据链：

```text
① 资源表写着          USART2 for F103        → H743 的 USART2 专门连 F103
② 全部 H 桥/DShot 定时器都在 H743（Timer1/3/5/8/15/16/17）
   → F103 不承担电机输出，所以它不是 Pixhawk 那种 I/O 协处理器
③ 原理图里 F103 有自己的 8MHz 晶振、NRST1、BOOT0、SWD（SWDIO1/SWCLK1）
   → 它是一颗能独立跑程序的 MCU
```

**结论**：F103 就是我们自己写逻辑的地方（回传/裁判/任务扩展），
与 H743 之间用 **USART2** 通信。这与最初「板B 跑任务逻辑」的方案一致。

### 5. 4 路 ESC 接口带独立 UART → 支持双向 DShot 遥测
ESC 座子（U13/U11/U14/U15）各带 DShot + 电流采样 ADC + 一路 UART
（UART4 / USART6 / UART7 / UART8）→ 可读电调转速/温度/电压。

## 五、连接 QGC 的方案（不需要 USB）

```text
飞控 TELEM 串口座（GH1.25）
   → GH1.25 转杜邦线
   → USB-TTL 模块（CH340 / CP2102 / FT232，¥10~20）
   → 电脑 USB
   → QGC 自动识别
```

接线三条线（**必须交叉**）：

```text
飞控 TX  →  模块 RX
飞控 RX  →  模块 TX
飞控 GND →  模块 GND
```

> ⚠️ **电平注意**：H743 的 UART 是 **3.3V** 逻辑。
> 用 5V 逻辑的 TTL 模块**可能打坏 IO**。选带 3.3V/5V 跳线且能设 3.3V 的模块。

无线方案（可选，不用拴线）：

```text
① 数传电台（SiK / 思翼 3DR 兼容，¥100~200）→ 插 TELEM 口，PX4 原生识别，零代码
② ESP32 WiFi 桥（¥20）→ 要刷固件，便宜但折腾
```
