## 二、给硬件队友的接口需求清单（可直接转发）

### A. 机架（机械）
- [ ] UWB 标签安装位：顶部/无金属遮挡（碳板导电会屏蔽信号）
- [ ] 全包围桨保接口（新规强制，结构早留）
- [ ] Marker 贴纸位：机腹底部（机库认你用）
- [ ] 磁吸+充电触点位：机腹底部居中
- [ ] 电池仓：对应 30s 储能小电池，位置可微调（调重心）
- [ ] 飞控减震：橡胶/泡沫减震（IMU 怕振，头号坑）
- [ ] 重心：电池/飞控/UWB 居中

### B. 飞控板（若自研 PCB）
- [ ] UWB 标签接口：UART 或 SPI
- [ ] 4 路 DShot 输出（定时器资源够）
- [ ] SBUS 接收机 UART（注意反相）
- [ ] 充电触点 + 数据引脚（触点引到板，大电流走线加粗）
- [ ] 光流接口（I2C/SPI 预留）
- [ ] 机载算力 UART（预留）
- [ ] 黑匣子：Flash 或 SD
- [ ] 电池电压检测（分压 ADC，回库触发用）
- [ ] 减重：小封装少冗余
- [ ] 若跑 PX4：满足 PX4 硬件兼容清单

### C. 系统级（易忘）
- [ ] 天线/信号线走线：不被碳纤维包住（碳纤维导电屏蔽）
- [ ] 线束轻量化（249g 线重不可小觑）
- [ ] 桨保重量早算进预算
- [ ] 可维护性：快速换电池/桨/拆机（比赛现场 5 分钟修好）

### D. 机库
- [ ] 充电触点+磁吸+到位开关
- [ ] 摄像头（认 Marker）+ 漏斗/导引
- [ ] 通讯网关（ThreadX 板）+ 有线到操作间
- [ ] 裁判系统接入

## 三、和硬件队友三个必谈点
1. 249g 重量预算谁管：先定总账（150g 起算），每克有归属
2. UWB 安装位 + 减震 + 重心：直接口头确认落实（影响定位/稳定）
3. 接口留冗余：现在用不上的 UART/I2C 都留，改板子成本极高，留引脚便宜

## 四、硬件路线分阶段（2026-08-29 与硬件队友对齐后）

> 队友初步方案：F4 板 + 基础模块 + 电池，先飞起来小的，逐步完善。方向确认 ✅，补充技术路线：

| 阶段 | 硬件 | 固件 | 能力 | 对应课程 |
|------|------|------|------|---------|
| 1 练手 | F405 板 + 四合一电调 + 电机桨 + 电池 + ELRS 接收机 | **Betaflight** | 手动/自稳飞行 | L01-L03 手感 |
| 2 半自主 | 同上 +（室外 GPS / 室内光流） | **INAV** | 定点/航点 | L04 前置 |
| 3 全自主 | **换 F7/H7 板**（F4 新版 PX4 已不支持）+ UWB 标签 | **PX4** | offboard/UWB/回库 | L04/L05 |

**下单前对齐两点**：
1. 板子 UART ≥4 个空余（以后接 UWB/数传，省得换板）
2. 全包围桨保记得排进机械（RM2027 硬要求）

**开发环境分工（2026-08-29 确认）**：PX4/仿真 → WSL Ubuntu（已就绪，`E:\WSL\`，已从 C 盘搬出）；rm_2027 STM32 固件 → Windows 侧 Keil/MSYS2 照旧；编辑 → Windows VSCode + Remote-WSL。两条工具链互不干扰。
