## 七、★ 三套无人机学习课程（2026-08-28 追加，用户发来）

### 7.1 尚硅谷《无人机教程，零基础手搓无人机》（硬核飞控全流程）
- **BV1f8rbBSEq3** · 播放 **89.5万** · 收藏 3.3万 · **140 集 / 33.5h** · 免费（公众号"尚硅谷教育"回"无人机"领资料）
- 内容：**从 PCB 到飞控软件全流程**——嘉立创EDA画原理图/PCB（STM32主控+MPU6050+SI24R1 2.4G+激光测高+电源）→ CubeMX/FreeRTOS → MPU6050采集 → 滤波（低通/卡尔曼）→ 姿态解算（互补/四元数）→ PID 控制与调参 → 定高（激光测距）→ 遥控器 → 故障处理
- 全目录已存 `references/尚硅谷-无人机课程-140集目录.txt`
- 定位：**"自研飞控"路线主教材**，与你的 STM32/ThreadX/BMI088 底子完全同构；RM2027 249g 微小型机若要自研轻量飞控，这门课是核心

### 7.2 浙大博导《带你从0制作无人机》（理论深度）
- **BV1cM4y1Z7Zs** · 播放 27.9万 · 收藏 2.8万 · **6 集 / 6.5h**（UP: TechTorch1 转）
- 内容：P1 旋翼无人机导论 / P2 软硬件架构 / P3 控制算法 / P4 控制器算法仿真 / P5 感知算法 / P6 路径规划及轨迹规划
- 定位：**理论补课**——补 Fast-Drone-250 课程"不赘述"的动力学/控制/感知/规划理论；P3 控制算法 + P4 仿真 + P5 感知最重要
- 附：P1 导论字幕已抓 `bili_temp/BV1cM4y1Z7Zs_ZJU_P1_导论.txt`

### 7.3 琛光《45元成本手搓无人机》（最小系统低成本上手）
- **BV18ho4BKEzt** · 播放 **40.3万** · 点赞 1.7万 · 1 集 / 22min
- 内容：ESP32 + 1 个陀螺仪 + 自带 WEB 遥控器（手机连 WiFi 起飞），硬件开源 `oshwhub.com/songge8/project_qqqyfdkm`，固件开源 `github.com/songge8/CF-Drone`
- 定位：**最便宜的"能飞"体验**（45 元），快速建立从传感器到飞行的直觉；功能过简（无定高无定位），只当入门手感，不是 RM 目标
- ⚠️ 该视频 B站 AI 字幕串台（内容是央视频 App 测评），字幕不可用，以简介+开源仓库为准

> 三套课分工：**尚硅谷=飞控硬核(动手)** · **浙大博导=理论深度** · **45元=低成本手感**。与 Fast-Drone-250 课程（自主机复刻）配合成完整学习矩阵。
