# RM2027 无人机硬件需求 v1（给硬件组，可转发）

> 2026-09 定稿草案。赛规未出，此为技术路线版（不绑死赛规对接）。
> 方案一句话：**双 MCU**——板 A 跑 PX4（飞行+自主），板 B（F103RC）跑任务逻辑（回传/裁判/扩展），两板串口 MAVLink 互连。

---

## 板 A —— 飞控板（烧 PX4）

**建议：照 PX4 官方板 Kakute F7 抄引脚布局**（PX4 直接认，省去自适配）。

| 器件 | 型号 | 说明 |
|------|------|------|
| MCU | STM32F7 系（**F745VG**，Kakute F7 同款，PX4 官方 target） | 选能跑新版 PX4 的 F7 即可 |
| IMU | **MPU6500**（低成本）/ ICM-42688P（更优） | 两者 PX4 官方驱动都有（已查证） |
| 气压计 | **BMP280** 或 BMP388 | PX4 官方驱动 |
| 激光测距 | **VL53L1X**（I2C，~4m） | PX4 官方支持，**朝下装测地**（避桨气流） |
| 电机输出 | 4 路 PWM/DShot | 接电调→电机 |
| SBUS 遥控口 | 1×UART（SBUS 反相） | 现成 SBUS 接收机直连 |
| 连板 B | 1×UART（MAVLink） | |

## 板 B —— 任务板（跑你 ThreadX 逻辑）

| 器件 | 型号 | 说明 |
|------|------|------|
| MCU | **STM32F103RC**（64 脚，IO 多于 C8） | 跑你的任务代码 |
| 回传 | **NRF24L01**（SPI，焊死） | 姿态/电量/状态回传；可组网多机通信（扩展用） |
| 电池电压检测 | 分压+ADC | 电量监测/回传 |
| 裁判接口 | 预留（UART） | 赛规出后接 |
| 扩展 UART | 预留 1-2 路 | 备用（SBUS 转发/视觉通信预留） |

## 两板连接
板 A UART ↔ 板 B UART（**MAVLink**）：板 B 读飞控状态、发 offboard 指令。

---

## 已查证的事实（PX4 源码/文档）
- F7 跑新版 PX4：✅ 官方大量板支持（Kakute F7=F745VG 等）
- MPU6500 / ICM-42688P：✅ 官方驱动在源码
- BMP280/BMP388/DPS310：✅ 官方驱动在
- VL53L1X / TFmini：✅ 官方支持（VL53L1X I2C~4m / TFmini UART~12m）
- SBUS 直连飞控 UART：✅ PX4 原生

## 重量约束提示（249g）
- 器件选轻封装；PCB 尽量小；每颗料报重量
- IMU/气压/测距合计目标 <10g；MCU 芯片本身 <2g
