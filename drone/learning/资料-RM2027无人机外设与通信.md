# 资料 · RM2027 无人机外设与通信（系统架构问答）

> 2026-08-28 建立。回答"RM 语境下要哪些外设/遥控器/UWB/光流/PX4/相对定位/通信"系列问题。
> 依据：RM2027 官方规则亮点（249g/机库/30s/撞击拦截侦察）+ 飞控通识。

## 一、系统三层架构

```
【机载侧 ≤249g】         【机库（重量不限）】         【场外/操作间】
飞控板(IMU+气压计)        充电管理                    操作手/决策
电机×4+电调+桨+桨保       起降引导(定位/视觉)          雷达
电池(储能限制≈30s)        通讯网关(有线/近场无线)      
UWB 标签 ──UWB基站──→   裁判系统接入                 
遥控接收机 ──SBUS──→     信息汇聚(侦察转发)           
(可选)轻量传感器/算力      4机调度中心                 
   ↕ 近场无线/有线(回传)   ↕ 有线(到操作间/雷达)
   ↕ 充电接触
```

> 官方设计：侦察信息"有线或近场无线传回机库"→ 机库是通信枢纽 → 飞机省掉大功率图传数传（省重量省电），249g 才成立。

## 二、外设清单

### 机载（必须）
- 飞控板（IMU+气压计，黑匣子）
- 电机×4 + 电调 + 桨 + 全包围桨保
- 电池（储能受规则限制≈30s）
- **UWB 标签**（定位，预计必须，待规则书）
- 遥控接收机（SBUS/ELRS，测试/应急接管）

### 机载（可选，249g 很紧，按预算加）
- 轻量摄像头（侦察）
- 测距/碰撞感知（拦截/撞击）
- 机载算力（能塞才塞）

### 机库（重量不限，你们主场）
- 充电模块（触点/磁吸）
- 起降引导（UWB/视觉/机械）
- 通讯网关（有线/近场无线回传）
- 裁判系统接入

> 无 GPS、无大图传。RM 室内靠 UWB 定位，回传靠机库。

## 三、逐问解答

### Q: 要接遥控器吗？
开发/测试阶段**必须有**（解锁/紧急停桨/手动接管=紧急刹车）。比赛自主为主，但**留手动接管通道是标配**。

### Q: 遥控器方案？
- 乐迪 T8FB/AT9S（便宜 SBUS）或 **TX16S + ELRS**（推荐：低延迟低价，接收机轻）
- 要求：**≥6-8 通道**，留 解锁/模式切换/紧急停桨。

### Q: 重量怎么分配（249g 预算）？
典型估算：电池 30-40% · 机架+桨保 25-30% · 动力 20-25% · 飞控+传感器 10-15% · 通信(标签+接收机+线) 5%。
战略：**从 150g 起增量设计**，先能飞+能定位，再加侦察/算力。

### Q: 用什么接收机？
取决于协议：**SBUS**（通用）/ **CRSF**（穿越机系）/ **ELRS**（新式推荐）/ DSMX。接收机几克。重点：把解锁/停桨通道接好。

### Q: 要不要跑 UWB？
**大概率要**（场内无 GPS，定位命门；ZJU 高飞验证）。**等规则书**确认场地是否提供定位服务。备选：光流+视觉里程计 / 融合。

### Q: 光流接口是啥？
光流=光学鼠标原理测水平速度（I2C/SPI 输出）。与 UWB 区别：
| | UWB | 光流 |
|--|-----|------|
| 输出 | 绝对位置（相对基站） | 相对地面速度（积分位移，会漂） |
| 用法 | 场边布站做绝对定位 | 悬停短时辅助 |
最佳：UWB 绝对 + 光流/IMU 融合（EKF）。

### Q: PX4 是啥？
PX4=开源的"飞控操作系统"（固件，非硬件）：传感器驱动+EKF 估计+控制律+MAVLink+任务/offboard。
类比：PX4 之于无人机 ≈ mas_embedded_threadx 之于步兵。
竞品：Betaflight（手动竞速）/ ArduPilot（航测）。RM 自主路线用 **PX4**（offboard 接外部定位/控制）。

### Q: 相对定位与识别视觉？
- 相对定位：UWB 机间测距（EGO-Swarm）或视觉看到对方。
- 识别视觉：轻量摄像头+算力跑检测；拦截还要视觉追踪弹丸+弹道预测。
- **249g 矛盾**：重算力超重 → 重识别大概率放机库/场外（地面算力），机载只做轻量感知，或靠裁判/雷达给目标信息。待规则书 + 算力分配决策。

### Q: 通信分层？
| 链路 | 介质 | 内容 |
|------|------|------|
| 机载↔飞控 | 内部 UART/MAVLink | 姿态/指令 |
| 机载↔机库 | 近场无线/有线 | 状态、侦察数据 |
| 机库↔场外 | 有线/数传 | 侦察→雷达/操作间、调度 |
| 4 机间 | UWB/WiFi mesh | 相对位置、协同 |
| 遥控↔机载 | SBUS/ELRS | 手动接管（测试/应急） |

核心洞察：**重通信走机库（有线/近场），机上通信负担轻** → 249g 成立；机库通讯网关是你们电控主战场之一。

## 五、补：机载 vs 飞控 · PX4 跑在哪 · 有线/近场无线怎么传

### 5.1 机载 vs 飞控（不是对立，是分工）
- **飞控（FC）** = 一块板 + 固件，管"稳定"（姿态估计/控制律/电机输出）。类比：底盘/云台下位机（STM32）。
- **"机载"** 广义=所有装在飞机上的东西（飞控也是机载的）；狭义（RM 语境）= **飞控之外的第二块更强计算板**（机载电脑：NUC/树莓派/NX），管"聪明"（视觉/规划/决策）。类比：上位机。

### 5.2 PX4 跑在单片机（就是 STM32 类 MCU）
| 板 | 跑什么 | 干什么 | 类比 |
|----|--------|--------|------|
| 飞控板 MCU（STM32 F4/F7/H7） | **PX4 固件**（NuttX RTOS） | 底层实时：IMU 融合/姿态位置控制/电机输出 | 下位机 STM32 |
| 机载电脑（NUC/树莓派/NX） | Ubuntu+ROS+视觉/规划 | 高层智能：感知/规划/决策 | 上位机 |

> 选飞控板 = 选一块"能跑 PX4 的 STM32 板"。与你们"下位机+上位机"架构同构。

### 5.3 有线/近场无线怎么传（RM2027 设计核心）
- **为什么**：30s 就回库，侦察数据可"飞回来再传"，机上免大功率图传数传 → 省重量省电 → 249g 成立。
- **有线**：飞机落/贴机库时，触点/磁吸/插头接通；一条接触干两件事（充电 + 数据 UART/USB/CAN/以太网）。类比：手机放底座充电+同步。
- **近场无线**：短距（几米~几十米）、低功耗、小天线。技术：2.4G/5.8G 低功耗（近距 WiFi/BLE/私有）、UWB（定位+捎带数据）、NFC。类比：遥控器到接收机/蓝牙。
- **数据流**：飞机(近场无线/有线触点) → 机库网关(充电+汇聚) → 有线(以太网/串口) → 操作间/雷达/4机调度。
- **一句话**：机上只留"短距轻通信"，重数据全在机库用"有线"送出场外。

## 六、补：249g 到底要不要上位机（机载电脑）？—— 不要！

> 纠正误区：**"自主" ≠ "要上位机"**。Fast-Drone-250 的 NUC+ROS 是 1.1-1.2kg 豪华路线，RM2027 的 249g 用不上也不需要。

### 6.1 PX4 MCU 自己就能自主
PX4 跑在单片机，原生支持：航点飞行(mission)、offboard 外部控制(UWB 喂位置)、自动起飞/降落/返航、定点悬停。
→ **起飞→飞到点→撞击/拦截/侦察→回库降落充电** 这个核心循环，PX4 MCU + UWB 就够。

### 6.2 249g 最低配置（重量账）
| 部件 | 重量 |
|------|------|
| PX4 小飞控板 | 10-20g |
| 4×小电机+桨 | 40-80g |
| 电调 | 10-30g |
| 电池（30s 储能） | 30-50g |
| 机架+全包围桨保 | 40-80g |
| UWB 标签 | 5-10g |
| 接收机 | 3-5g |
| 合计 | ~150-250g（无上位机，刚好够） |

### 6.3 聪明活怎么解决（算力下放原则）
| 任务 | 要算力？ | 249g 解法 |
|------|---------|-----------|
| 飞航点/回库/UWB 定位 | 否 | PX4 MCU 直接干 |
| 拦截（看弹道） | 是 | 算力放机库/场外（地面算力），机上只带轻量传感器 |
| 撞击（对准目标） | 需目标位置 | 靠裁判/雷达给坐标，不用机上视觉 |
| 侦察（画面） | 传数据 | 轻量摄像头 + 回库再传（有线/近场） |
| 4 机协同 | 需相对位置 | UWB 相对测距（标签即可） |

> **核心原则：能下放到地面的算力都下放**（机库/场外），机上只留"传感器+PX4 MCU+UWB"。这是 249g 成立的第二腿（第一腿=重通信走机库）。
> 修正建议：249g 路线 = **PX4 小飞控 + UWB 定位 + 机库地面算力**，不烧钱、难点在"UWB 准不准 + 回库降稳不稳"（软件/算法问题）。

## 四、待规则书确认的点
1. 场地是否提供定位服务（决定机上 UWB 是否必须）
2. 是否允许/需要遥控器手动参与
3. 撞击/拦截的具体判定（决定感知需求）
4. 机库通信的具体形式（有线 vs 近场无线）
