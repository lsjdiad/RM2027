# PX4 构建系统 · 00-08 分层笔记

> 写法：像 L00 / L01 / L02 那样，一层只讲一件事。
> 目标：把 `make px4_sitl gz_x500` 从“命令”拆到“飞机怎么飞”。

---

## 00 · 总览

一句话：

```text
Makefile = 调度
CMake    = 图纸
Ninja    = 施工
px4      = 主控
rcS      = 上电
4001     = 机型
model.sdf = 机械
gz_bridge = 总线
QGC      = 遥控
```

---

## 01 · 命令入口

命令：

```bash
make px4_sitl gz_x500
```

在 `Makefile` 里被拆成：

```text
FIRST_ARG = px4_sitl
ARGS      = gz_x500
```

对应关系：

```text
px4_sitl  ≈ 选择“板级配置”
gz_x500   ≈ 选择“运行哪个仿真模型”
```

---

## 02 · 调度层

文件：

```text
Makefile
```

核心函数：

```make
define cmake-build
```

它只做三件事：

```text
1. 准备 build/px4_sitl_default
2. 必要时运行 cmake 配置
3. 运行 cmake --build -- gz_x500
```

电控类比：

```text
Makefile ≈ 总调度表
cmake-build ≈ 调度员
```

---

## 03 · 构建层

### 03.1 CMake

文件：

```text
src/modules/simulation/gz_bridge/CMakeLists.txt
```

作用：

```text
定义 gz_x500 目标
```

它最终生成：

```text
build/px4_sitl_default/build.ninja
```

### 03.2 Ninja

作用：

```text
真正调用编译器 / 链接器
生成 px4 二进制
```

电控类比：

```text
CMake ≈ 工程图纸
Ninja ≈ 施工队
```

---

## 04 · 运行层

文件：

```text
ROMFS/px4fmu_common/init.d-posix/rcS
```

它做的事：

```text
看到 PX4_SIM_MODEL=gz_x500
→ 匹配 4001_gz_x500
→ 设置 SYS_AUTOSTART=4001
```

然后执行机型脚本：

```text
ROMFS/px4fmu_common/init.d-posix/airframes/4001_gz_x500
```

里面设置：

```text
CA_ROTOR_COUNT 4
CA_ROTOR0_PX / PY / KM
SIM_GZ_EC_*
```

电控类比：

```text
rcS ≈ 上电启动流程
4001_gz_x500 ≈ 机型参数表
```

---

## 05 · 仿真层

启动脚本：

```text
ROMFS/px4fmu_common/init.d-posix/px4-rc.gzsim
```

启动：

```text
gz sim
gz_bridge
```

模型文件：

```text
Tools/simulation/gz/models/x500/model.sdf
```

定义：

```text
机身
4 个电机
桨
传感器
```

电控类比：

```text
model.sdf ≈ 机械 / 电机模型
gz_bridge ≈ CAN / SPI 驱动桥
```

---

## 06 · 人机层

QGC：

```text
连接 MAVLink
看姿态 / 高度 / 模式
发任务 / 解锁 / 起飞
```

电控类比：

```text
QGC ≈ 遥控器 + 地面站
```

---

## 07 · 飞行闭环

```text
1. Gazebo 给出假传感器数据
2. gz_bridge 转给 PX4
3. PX4 跑姿态 / 位置控制
4. PX4 输出电机转速
5. gz_bridge 转给 Gazebo
6. Gazebo 更新飞机位姿
7. 回到第 1 步
```
