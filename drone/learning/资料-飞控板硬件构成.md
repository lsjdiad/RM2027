# 资料 · 飞控板硬件构成（自研/画板参考）

> 2026-08-28 建立。来源：结合尚硅谷 140 集课程（P10-50 嘉立创EDA画板）+ 现代飞控（Betaflight/PX4 系）构成 + RM2027 249g 需求。
> 用途：你要自己画飞控板时的"硬件清单/选型"参考。

---

## 一、一句话总览

> **飞控板 = 主控 MCU（算）＋ 姿态传感器 IMU/气压计（感）＋ 电源树（供电）＋ 电机/电调输出（动）＋ 通信接口（连）＋ 存储/调试（记）**，RM 自主机再叠加位（UWB/光流）与机载算力接口。

## 二、六大模块清单

### ① 主控 MCU
- 需求：跑飞控固件（姿态解算+控制律），够算力 + 够多定时器/UART。
- 选型：**STM32 系**——F405（教学/入门）、F722/F765（主流 Betaflight）、H743（高端 PX4）。
- 关键决策：**跑什么固件决定板子下限**（PX4 要求 F4/F7/H7 + 特定传感器组合；自研可更省）。
- 尚硅谷教学板：STM32F1xx；RM 249g 实战建议：F405/F722 级。

### ② 传感器（飞控灵魂）
| 传感器 | 测什么 | 常用型号 |
|--------|--------|---------|
| IMU 六轴（陀螺+加计） | 角速度+加速度 → 姿态解算 | MPU6050（教学）/ MPU6500 / ICM-20602 / **ICM-42688 / BMI088**（RM 常用） |
| 气压计 | 高度（定高） | BMP280 / MS5611（基本必备） |
| 磁力计 | 航向参考（建议） | QMC5883L / HMC5883L / IST8310 |
| 光流（可选） | 水平速度/定位 | 光流模块（RM 自主机需要） |
- 接口 I2C/SPI；双 IMU（冗余/标定）为高阶配置。

### ③ 电源系统（供电树）
- 输入：电池（1S/2S 小机；RM 249g 按储能限制选）。
- 稳压：电池 → 5V（BEC/DC-DC）→ 3.3V（LDO）。
- 电压检测：电阻分压 + ADC（低电报警/回库触发）。
- 电流检测（可选）：采样电阻 + INA。
- 保护：防反接 / 过压 / TVS。

### ④ 电机/电调输出
- **≥4 路**电机输出：**PWM 或 DShot**（定时器 + DMA）。
- 教学板：板载 MOS 直驱；实战板：DShot 信号给外置电调。
- 关键：定时器资源要够 4 路以上。

### ⑤ 通信接口
| 接口 | 连什么 |
|------|--------|
| UART | 接收机（SBUS/CRSF/ELRS）、数传（MAVLink）、GPS（可选） |
| USB Type-C | 配置/调参/DFU/日志 |
| I2C/SPI | 外置罗盘、光流、扩展 |
| （RM）机载算力 UART | 接 NUC/树莓派等 |
| （RM）图传 | 侦察回传（可选） |

### ⑥ 存储 + 调试
- 黑匣子：板载 Flash（W25Q128）或 SD/TF 卡槽（日志，炸机复盘必备）。
- SWD 烧录调试 + BOOT + 状态 LED + 蜂鸣器（可选）。

## 三、三版对比

| 模块 | 尚硅谷教学板 | 现代 Betaflight/PX4 板 | RM 249g 实战板 |
|------|-------------|----------------------|----------------|
| MCU | STM32F1 | F4/F7/H7 | F405/F722 |
| IMU | MPU6050 | 双 IMU(ICM/BMI)+磁+气压 | ICM/BMI+磁+气压 |
| 定位 | 激光定高 | 外接 GPS/光流 | **UWB/光流接口**（无 GPS） |
| 电机输出 | 板载 MOS 直驱 | 4-8 路 DShot | DShot 4 路 |
| 通信 | SI24R1 自研 2.4G | SBUS/CRSF+USB | SBUS+机载 UART+数传 |
| 存储 | 无 | Flash/SD 黑匣子 | Flash 黑匣子 |

## 四、RM2027 选型要点（249g 硬约束）

1. **减重第一**：板子只是几十克，但每克记账；小封装、少冗余。
2. **固件决定下限**：跑 PX4 → 满足其硬件要求；自研轻量 → 更省。
3. **UWB/光流接口必须预留**：RM 场内无 GPS，定位是命门。
4. **黑匣子必须有**：自主机调试/炸机复盘靠日志。
