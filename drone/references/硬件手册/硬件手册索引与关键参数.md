## 一、这两块板是什么

### 1. FMU 飞控板

文件：

```text
FMU_飞控板_原理图_2026-09-24.pdf
```

核心组成：

```text
主控：STM32H743VIT6
协处理：STM32F103C8T6
IMU：ICM-42688-P（SPI1）
磁罗盘：IST8310（I2C4）
气压计：SPA06-003（I2C2）
外置陀螺：H104（CAN1 / USART1）
CAN 收发器：SIT3051TK ×2（CAN1 / CAN2）
电源：SY8303（5V）+ TLV75533（3.3V H7 / 3.3V F1）
```

### 2. ESC 电调板

文件：

```text
ESC_电调板_原理图_2026-09-24.pdf
```

核心组成：

```text
主控：STM32G071GBU6N
三相栅极驱动：FD6288Q
功率级：Q1~Q6 三相半桥 MOSFET
电流采样：INA240A1PWR
DShot 输入接口
VBAT 电压采样
Buck：SY8303（Back to 6V）
LDO：TLV76733（3.3V）
RGB：WS2812B
```

## 三、原理图里值得注意的连接

### FMU

```text
ICM-42688-P  → SPI1
IST8310      → I2C4
SPA06-003    → I2C2
H104         → CAN1 + USART1
CAN1/CAN2    → SIT3051TK
H7 ↔ F103    → USART2
SWD          → 调试
USB          → 配置 / 刷写
```

### ESC

```text
DShot 输入   → G071
G071         → FD6288Q → Q1~Q6
INA240       → 电流采样
VBAT_SENSE   → 电压采样
SY8303       → Back to 6V
TLV76733     → 3.3V
WS2812B      → 状态灯
```

## 四、使用方式 / bring-up 重点

### ICM-42688-P

```text
接口：SPI1
关键：SPI 模式、CS、时钟、数据就绪中断
PX4 驱动：src/drivers/imu/invensense/icm42688p
```

### IST8310

```text
接口：I2C4
地址：0x0E
PX4 驱动：src/drivers/magnetometer/isentek/ist8310
```

### SPA06-003

```text
接口：I2C2
PX4 驱动：src/drivers/barometer/goertek/spa06
ID：0x11
```

### FD6288Q

```text
输入：HIN1~3 / LIN1~3
输出：HO1~3 / LO1~3
关键：200ns 死区，UVLO，直通保护
```

### INA240

```text
输出：模拟电压
A1 增益：20V/V
用途：电流环 / 过流保护
```

### SIT3051TK

```text
接口：CANH / CANL
速率：1Mbps
模式：高速 / 斜率控制 / 待机 / 关断
```
