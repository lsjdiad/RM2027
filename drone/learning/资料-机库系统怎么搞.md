# 资料 · 机库系统怎么搞（停稳/充电/传数据）

> 2026-08-28 建立。RM2027 无人机机库三大工程问题：停得准、充得快、传得出。
> 依据：RM2027 官方规则（机库≤300×300×200mm、4架、30s 续航、有线/近场回传）+ 工程通识。

## 〇、核心矛盾
**UWB 精度仅 ~10-30cm，充电触点容差却要 mm 级** → UWB 不够直接怼准，必须**多级引导**。

## 一、怎么停稳（多级引导，粗→精）
```
UWB 粗定位(~20cm) → 视觉 Marker 精定位(cm) → 机械漏斗/磁吸兜底(mm) → 到位确认
```
| 级别 | 方案 | 精度 | 原理 |
|------|------|------|------|
| ① 粗定位 | UWB | 10-30cm | 飞到机库正上方附近 |
| ② 末端精定位 | 视觉 Marker（AprilTag/ArUco） | cm | 识别机库二维码 → 相对位置 → 对准降落点 |
| ③ 机械兜底 | 漏斗开口/斜面/磁吸 | mm | 最后几厘米"滑"进槽 / 磁铁吸正 + 保接触 |
| ④ 到位确认 | 触点导通检测 + 到位开关 | — | 确认坐稳才允许充电 |

> ①②③ 多级叠加，不是选一。重装备（摄像头/磁铁/漏斗/算力）放**机库侧**（重量不限），飞机侧只加 Marker 贴纸 + 磁铁 + 触点（几克）。

## 二、充电方案
| 方案 | 原理 | 优缺点 |
|------|------|--------|
| 触点充电（推荐） | 铜触点/弹片 + 机库电极 | 简单可靠效率高；注意防反接/氧化/大电流发热 |
| 磁吸充电（推荐） | 磁铁+触点一体 | 吸正+导电一举两得 |
| 感应充电 Qi | 电磁耦合 | 效率低发热，30s 快充场景不划算 |
- 管理：BMS 芯片（BQ25100/BQ25601 类）+ 限流 + 防过充 + 充满判定。
- ⚠️ **快充矛盾**：30s 用完 → 充电速度=出击频率。飞30s充10min=整场在充电。要"快充 vs 安全"平衡（小电池不能盲冲大电流）。

## 三、传数据
- **有线（触点数据线）**：触点加数据引脚（UART/USB/CAN/以太网），落稳接触后传 侦察/日志/状态。注意接触抖动 → 通信要握手/重传。
- **近场无线**：2.4G 低功耗（近距 WiFi/BLE/私有，几米-几十米）；**UWB 定位+捎带传数据**（LinkTrack 双向）；NFC（贴近握手/身份）。
- 传什么：侦察图像(压缩)、日志、状态、指令。

## 四、完整时序
```
① 任务结束/低电 → PX4 返航
② UWB 粗定位到机库上方
③ 摄像头认 Marker → 对准降落点
④ 磁吸/漏斗吸稳 + 触点导通 + 到位确认(停稳)
⑤ 充电管理启动(限流快充)
⑥ 数据线/近场无线传数据+日志+状态
⑦ 充满/到点 → 解锁 → 下次出击
```

## 五、工程分工
| 事 | 飞机侧(249g 省着加) | 机库侧(重量不限) |
|----|--------------------|-----------------|
| 停准 | Marker+磁铁+触点 | 摄像头(认Marker)+漏斗/磁吸+到位开关 |
| 充电 | 电池+充电管理(轻)+触点 | 电源+限流+充满判定 |
| 传数据 | 触点数据脚/轻无线 | 网关(ThreadX板)+有线转发场外 |

## 六、结论
机库=你们电控"另一半主场"。三件事里最难：**多级降落引导（停稳）** 和 **快充平衡**，都是软件+小硬件可解，不需要大算力。
