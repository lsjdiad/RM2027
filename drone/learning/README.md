> 面向：有嵌入式底子的 RM 电控（会用 C/RTOS/串级PID/电机/裁判，但无人机全新）。

## 二、怎么学（学习法）

1. **概念用类比**：每课先说"这像你会的什么"——云台串级PID、RTOS 线程、CAN 通信，都能对号入座。
2. **做完实验才算过**：光看不做 = 没学。每课 lab 有明确"验证标准"，达不到就回头。
3. **边学边查开源**：每课配"对照开源"，读 Fast-Drone-250 / PX4 源码对应部分。
4. **记笔记到 lab/**：每课实验记录（参数/截图/报错/结论）放 `learning/lab/<课号>/`，沉淀下来。
5. **别背名词，追因果**：每个概念问一句"为什么需要它"，答不上来就回看。

## 四、你需要提前知道的三件事（先说透）

1. **你不是从零**：你会串级PID（云台）、RTOS 任务、电机/PWM、CAN——无人机 80% 的工程概念你都会，差的是**飞行的物理直觉 + PX4/定位生态**，这两块补上就通了。
2. **别被"249g"吓到**：它反而是**最简单的门槛**（不用大功率、不用云台、不用图传），难的是**自主**（定位+回库）。
3. **环境先装好再谈别的**：L00 装 PX4 SITL 是本课程第一道坎，装好之后每课都能在仿真里验证，不烧钱不炸机。
