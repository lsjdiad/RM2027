# 开发日志 10 —— 修掉「参数一断电就丢」（片内 flash 参数存储）

> 状态：**代码完成 + 编译通过（PX4 `be9f428`，分支 `bringup/imu-polled-and-params`）；
> 尚未上板验证，也没有烧写**（ST-Link 需物理重插；且本改动动了链接脚本，等用户确认）。

---

## 1. 问题

PX4 的参数默认存在 **SD 卡** 的 `/fs/microsd/params`。
`FLASH_BASED_PARAMS` 没打开时就走这条路。

**本板既没有 SD 卡、也没有 USB** ⇒ 参数根本存不下来：

```text
开机日志（实测）：/fs/mtd_params failed (-1) attempt 1
                  parameter storage empty
                  param load-or-init failed
```

后果：

| 影响 | 说明 |
|---|---|
| **标定全白做** | 陀螺/加计标定结果一断电就丢 —— 直接卡住「调 gyro/accel 参数」这个目标 |
| **`SYS_AUTOSTART` 改不了** | 下游导致 `No airframe file found` → `ERROR [ekf2] start failed (-1)` |

（对照：`matek/h743` 也把 `FLASH_BASED_PARAMS` 注释掉了 —— **因为它有 SD 卡**。
这也是为什么照抄 matek 的板级模板会踩这个坑。）

## 2. 改动（4 处）

| 文件 | 改动 |
|---|---|
| `nuttx-config/scripts/script.ld` | `FLASH LENGTH 1920K → 1792K` |
| `src/board_config.h` | 打开 `#define FLASH_BASED_PARAMS` |
| `src/init.c` | 打开参数初始化（+ 打开被注释的 `#include <parameters/flashparams/flashfs.h>`） |
| — | 扇区表用 `{15, 128 * 1024, 0x081E0000}` |

### 为什么必须改链接脚本

STM32H743 是 **2MB = 2 bank × 8 个 128K 扇区**。
bank2 最后一个扇区 = **扇区 15 = 0x081E0000**，正好在 app 区尾部之外。

链接脚本原来写 `LENGTH = 1920K`（到 0x08200000），**把参数扇区也圈进 app 的可放置范围**。
一旦哪天代码长大放进 0x081E0000，参数写入就会**擦掉代码**。
所以必须把 LENGTH 缩到 **1792K**（0x08020000 + 0x1C0000 = **0x081E0000**），把那个扇区彻底让出来。

### 为什么只要一个扇区

同 MCU 的 4 块参考板全部是**单扇区**：

| 参考板 | 扇区表 | LENGTH |
|---|---|---|
| `aedrox/aedroxh7` | `{15, 128K, 0x081E0000}` | 1792K |
| `corvon/743v1` | 同上 | 1792K |
| `corvon/743v2` | 同上 | 1792K |
| `cbunmanned/h753-som` | 同上 | 1792K |

`flashfs32.c` 的 `get_next_sector_descriptor()` 在只有一项时会**回到自己**：

```c
if (sector_map[s + 1].address) { return &sector_map[s + 1]; }
// 只有一项：回到自己
return &sector_map[s];
```

⇒ 单扇区是合法配置。**代价：没有扇区级磨损均衡**（每次 compact 都是擦同一个扇区）。
如果以后参数写得太频繁，可以改成 `{14, 0x081C0000} + {15, 0x081E0000}` 两扇区（LENGTH 改 1664K）。

### 为什么不用再加 NuttX 配置

- `CONFIG_STM32H7_PROGMEM=y` —— **本板 defconfig 里已经有了**。
  flashfs 走 `up_progmem_getpage/eraseblock/write` 接口，不需要 `CONFIG_MTD`。
- 片选 `CONFIG_ARCH_CHIP_STM32H743VI` 会自动 `select STM32H7_FLASH_CONFIG_I`
  ⇒ `STM32_FLASH_NBLOCKS = 16`、`SIZE = 2MB`、`STM32_DUAL_BANK = 1`
  ⇒ **扇区 15 在几何范围内**，`up_progmem_eraseblock(15)` 精确擦 0x081E0000 这 128K。

（`corvon/743v1` 里额外写了 `CONFIG_STM32H7_FLASH_OVERRIDE_I=y`，那是重复保险，本板不需要。）

## 4. 烧写后要确认的事

1. 开机日志里 `/fs/mtd_params failed (-1)` 和 `param load-or-init failed` **消失**
2. QGC 里改一个参数（例如 `SYS_AUTOSTART=4001`）→ **断电重启 → 参数还在**（这是最终验收）
3. 参数存下来之后：`SYS_AUTOSTART` 能设了 ⇒ 机架文件能加载 ⇒ `ekf2` 能起来
4. 然后才能做陀螺/加计标定（`CAL_GYRO*` / `CAL_ACC*`）

⚠️ 因为改了链接布局，这次烧写建议**先确认固件能正常启动**（QGC 能连上）再做别的。
如果起不来，回退到 `imu/bmi270-polled-data-regs`（不含本次改动）。
