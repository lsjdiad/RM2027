`AM32-rm2027/firmware/*.bin` 是按**分支名**命名的，`esc-lab.sh` 在每次编译后会删掉
"分支已不存在"的 bin ⇒ 一旦某个分支被删，它的 bin 也会被清掉。
所以凡是**要长期保留**的固件，都在这里放一份，并记清"分支 + 提交 + 开关 + 哈希 + 重建命令"。

## 2026-10-14 晚：丢过零滤波版（补偿 ON + RM2027_ZCL_FILTER，**只编译了、还没烧**）

用户方案原话："如果有 1 个 2 个过零识别不到就不管、按原来的频率继续跑；
如果多个识别不到就降低频率，这个降低速度要限制一下。"

实现在 test-04（补偿 ON）基础上，**唯一变量 = 丢过零滤波**：
- 超时阈值从 `1.5×ci` 改成 `ci + zcl_pred + ci>>5`（zcl_pred = 正常换相后记下的本步
  waitTime；超时换相后清 0）⇒ 丢 1~2 个过零时换相点落在"虚拟过零 + 30°"处 =
  本该换相的时刻 ⇒ **丢过零那一步的换相间隔 ≈ ci（保持原节拍）**；
- 连续丢 > 2 个：每步 `ci += ci>>6`（≈+1.56%/步，限速降频），真过零认到即恢复；
- 观测（SWD 读）：`tools/zcl-dump.py` → zcl_miss / zcl_miss_max / zcl_hold_n / zcl_slow_n / zcl_pred。
